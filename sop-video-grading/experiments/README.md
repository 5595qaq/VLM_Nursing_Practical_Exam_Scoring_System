# experiments

2026-10-29 起，每輪疊代的實驗紀錄一輪一個檔案，避免多人同時往 `EXPERIMENTS.md` 後面加而衝突（規則見 `AGENTS.md`「多人協作」）。之前的紀錄留在 `EXPERIMENTS.md`。

- 檔名：`YYYY-MM-DD-<主題>.md`，例如 `2026-10-30-10b-wrapper.md`；同一主題的下一輪另開新檔。
- 內容和 `EXPERIMENTS.md` 的每一節相同：做法、影片、一致率、不一致案例與歸因、版本（rubric、SKILL.md、切分）。
- 只寫影片 ID（`VID_0083`），不寫學生姓名，也不放影格圖片。
- 需要老師決定的事項寫進 `EXPERIMENTS.md` 的「待老師確認」，那裡是唯一的清單；這裡的檔案只連過去。
