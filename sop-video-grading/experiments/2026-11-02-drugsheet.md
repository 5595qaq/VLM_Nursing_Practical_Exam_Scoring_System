# 2026-11-02 實驗：給藥紀錄單改成先在畫面中找（drugsheet.1）

分支 `sop/drugsheet`，issue #116。評分 SKILL `0.34-drugsheet.1`（rubric 不動，1.20）；只跑評分步驟 2、4、29（`--steps 2,4,29`），commit 7c5cc5b。

## 問題

`criteria/02-drug-sheet.md` 仍寫舊考場「學生右後方牆上、點滴架旁的白色 A4」是給藥紀錄單，但使用者已確認那張紙不是紀錄單（`EXPERIMENTS.md` 2026-10-20）。held-out 驗證（`2026-11-01-heldout.md`）中，VID_0014 的紀錄單平放在治療車最前緣，0.34 照舊規則找牆上的紙，步驟 2、4、29 都判無法判定（藥單看不見）；人工核對為 2 錯誤、4 部分正確、29 錯誤。

## 做法

- 改 `criteria/02-drug-sheet.md`：
  - 先在畫面中找紀錄單，不預設位置。紀錄單是印有表格與文字的紙，常有螢光筆記號，多半平放在治療車最前緣（畫面下緣，可能被鐵架擋住一部分）或前方桌面。
  - 先用 context overview 看畫面下緣，再用 zoom 確認。
  - 整個區間都找不到才判「藥單看不見」，explanation 寫出找過哪些位置。
  - 牆上空白的紙不是紀錄單。
  - 紀錄單平放時，要分辨學生低頭是在看紀錄單，還是在看手上的藥瓶。
- 影片：
  - VID_0014：要修的影片。沿用 0.34 的 sop-video-skill 1.5.4 切分。
  - 回歸 VID_0001：紀錄單在治療車前緣，人工判 2、4 正確、29 錯誤。
  - 回歸 VID_0123：沒拍到紀錄單，應判無法判定。沿用 1.5.4 切分。
  - 回歸 VID_0072（舊考場牆上 A4）原本也要跑，但它沒有 1.5.4 的切分，重新切分到一半時停止（見「用量」），沒有結果。
- 比對標準：一致率用 2026-11-01 的人工核對（VID_0014，`2026-11-01-heldout.md`）、2026-10-21 的人工評分（VID_0001 步驟 29）與標記表，這些都在這輪之前完成。Claude 抽影格（確認紀錄單位置與讀紀錄單的時間）是在看過評分結果**之後**做的，只用來歸因，不用來算一致率。

## 不一致的歸因：切分找不到步驟 2、4

3 步不一致都是切分的問題，不是這次修改的規則：

- **VID_0001 步驟 2**：學生在洗手（00:40 起）**之前**，00:00–00:39 一直低頭看治療車前緣的紀錄單，並用手指指著（Claude 抽影格確認，標記表正確）。sop-video-skill 1.5.4 沒有找到步驟 2（`start`/`end` 為空），評分 agent 拿到的是洗手之後的 00:53–01:16，和正確時間差超過 `WINDOW_SLACK`（10 秒）。
- **VID_0014 步驟 2、4**：切分同樣沒有找到步驟 2、4。學生在 00:56 和 01:12 用右手手指按在紀錄單上（Claude 抽影格確認），這兩段都落在切分的步驟 3（00:54.8–02:15）。評分 agent 把 00:54–00:59 算進步驟 2（2b 正確），步驟 4 的區間只到 03:32，評分 agent 判沒有讀紀錄單（實際 03:28–03:56 有 2讀，見下方「0.35 重跑」的更正）。哪一次讀算 1讀、哪一次算 2讀，列入人工核對。
- 依 AGENTS.md，正確時間不在評分 agent 看得到的範圍內時，改 `sop-video-skill`（讓切分找出讀紀錄單的步驟 2、4），不在評分端補救。這次不改，另開 issue。
