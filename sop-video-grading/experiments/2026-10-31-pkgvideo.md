# 2026-10-31 實驗：10b 只用影片（pkgvideo.1）

分支 `feature/sop-10b-pkgvideo`（接在 PR #98 的 0.32／1.19 之後），issue #97。rubric `1.19-pkgvideo.1`、評分 SKILL `0.32-pkgvideo.1`，commit 2e89cc8；只跑評分（步驟 10），沿用 sop-video-skill 1.5.0 的切分（同 pkgspan.1）。

## 問題

使用者要求試試 10b 不用圖片、只用影片判斷。10b 要看的是旋轉這種連續動作，影格看不出來，所以想知道只看影片是否比 pkgspan.1（影格加影片）準。之前在全步驟做過影片和圖片的對照，那次是圖片勝出（`EXPERIMENTS.md` 2026-10-24）。

## 做法

- rubric 10b 新增 `video_only: true`。
- 開場不附 9 張影格，改附任務區間與手拿空針包裝時段的手部影片：
  - 畫面裁成 hands box，5 fps；
  - 相鄰時段合併，每段 ≤ 60 秒。
- 動作只能用 `clip`，共 4 次，可加 region、fps 10、每段 ≤ 8 秒。overview、zoom、burst 會被退回。
- 開場影片也算看過手拿包裝時段，所以判錯誤的條件不變。
- 影片：VID_0072、0081、0095、0097、0098、0099 各 1 次。合計約 69 萬 input tokens；pkgspan.1 的 #1 六支約 58 萬。

## 結果

| 影片 | 參考 | pkgvideo.1 | pkgspan.1（#1／#2） |
|---|---|---|---|
| VID_0072 | 錯誤（沒做） | **正確（誤判）**：說 01:37.9–01:43.0 多次旋轉，pkgspan.1 說這段是試活塞 | 錯誤／無法判定 |
| VID_0081 | 正確（02:20 短暫用力） | 正確，但依據是 01:47.7–01:48.3「旋緊」，不是 02:20 | 錯誤／錯誤 |
| VID_0095 | 錯誤（沒有固定） | **正確（誤判）**：說 00:45.2–00:48.5 隔著包裝旋緊，pkgspan.1 說這段是撕包裝 | 錯誤／錯誤 |
| VID_0097 | 正確（00:38–00:43） | 正確 00:38.0–00:41.7 隔著包裝 | 正確／正確 |
| VID_0098 | 正確（01:07–01:12 包裝內） | **錯誤（誤判）**：看了 4 段 clip，說 01:01–01:13.5 只是撥開包裝 | 正確／正確 |
| VID_0099 | 正確（00:40–00:54） | 正確 00:37.6–00:45.4 隔著包裝 | 正確／正確 |

- 判定和參考一致：**3/6**。依據的時間也對的只有 2/6（VID_0097、0099）。pkgspan.1 是 9/12，其中 #1 是 5/6。
- 判反方向的有 3 次：兩次把沒做判成正確（VID_0072、0095），一次把有做判成錯誤（VID_0098）。pkgspan.1 是 2 次，都是 VID_0081 把正確判成錯誤（取出後能看的範圍不夠），而且沒有把沒做判成正確的。
- 6 次都沒有失敗的任務，`grading.json` 都通過 `validate_grading.py`。
- 成本：每支 5.4–23.6 萬 input tokens。VID_0098 用了 4 段 clip，最貴。比 pkgspan.1 多約 2 成。

### 觀察（暫定）

- 只看影片時，agent 更常把手部的正常動作說成「旋轉固定」，例如試活塞、撕包裝、取出後調整握法（VID_0072、0095、0081）。pkgspan.1 有影格可以對照，這些段落都說對了。
- 反過來，VID_0098 包裝內的旋緊，pkgspan.1 兩次都看出來，這次卻說成撥開包裝。
- 和 0.20–0.28 的問題一樣：同一段畫面，在「旋緊」和「撕包裝／試活塞」之間跳動。只用影片沒有減少這種跳動，反而更多。

## 結論（暫定）

- 10b 只用影片比 pkgspan.1 差（3/6 vs 9/12），而且有 3 次判反方向，成本也較高。**建議不採用**，10b 維持 pkgspan.1（0.32／1.19，PR #98）。
- 和之前全步驟的對照一致：這個評分 agent 用影格加影片，比只用影片準。

**使用者決定（2026-10-31）：不採用，規則與程式修改已還原**（a020dca 撤銷 2e89cc8），只留執行紀錄與這份實驗紀錄；10b 維持 pkgspan.1（0.32／1.19）。要從對話紀錄重建影格時，用 commit 2e89cc8 的程式。
